# 松溪农场 · Pinebrook

TypeScript + Babylon.js 9.14.0 的原创体素农场游戏，Vinext/React 承载中文界面。场景、人物和环境特效均由代码生成。

## 四个大区块：农场、小镇、森林、海滩

- 地图扩大为 **96 × 80** 个等大的 1 × 1 方格，共 7680 格，约为原地图面积的 7.1 倍。
- 地图重排为西南农场、西北森林、东北小镇和东南海滩四个大区块。蜿蜒河流分隔两岸，三座加宽木桥与主路连接各区；彩色路牌、小地图和区域名称使用相同布局，维持固定 45° 方向。
- 农场有农舍、**12 × 9 格**菜圃、樱花果园、石井和大片可开垦草地；森林有分层松树、落木、蘑菇、宽林道与三处史莱姆战斗空地；海滩有宽阔沙岸、沙丘、四组遮阳伞、木栈道、贝壳和南侧码头；小镇的三栋建筑围绕石板广场展开，配有喷泉、长椅、花箱、路灯和蔬果摊位。
- 镇民路线、怪物出生点、资源拾取点、灯柱、桥梁水流和河鱼活动范围均迁移到对应区块；农舍及其烟囱、柴堆、信箱与庭院一起搬到新农场。四位居民沿镇街与海滩入口散步，另有一位巡林人。
- 大海采用顶点起伏波浪、深浅水渐变、近岸泡沫及随波变化的阳光反射。海上有七只盘旋振翅的海鸥、十八道缓慢游动且明暗变化的鱼影，以及五条错峰跃出水面的鱼和落水涟漪。
- 河流沿线有随机出没的鱼影，沿河道正向游动并摆尾，约 5–10 秒后渐隐，间隔 2–8 秒在新位置出现；大小、方向和路径各不相同，避开河岸与三座桥。复用 12 个鱼影位置，关闭环境动态时暂停游动和出没计时。
- 海鸥、鱼影和跃鱼的头部沿运动轨迹朝前；海鸥随升降轻微俯仰，跃鱼抬头出水、低头入水，落点跟随当地波浪，涟漪从落点扩散。
- 码头旁的小船可以驾驶，船体随波起伏，划桨与尾流响应移动。靠近小船按 E 登船，靠近岸边或码头按 E 下船；深水中不能直接离船。
- 四栋建筑均可直接步行进入，不更换场景。屋顶和前侧墙体平滑淡出，保留内部地板、床铺、桌椅、厨房、书籍或商店货架和柜台。门口真实开放，墙壁和家具参与碰撞。
- 镜头维持固定 45° 俯角和 45° 方位角的正交投影，只跟随人物平移。遮挡人物的树冠和建筑淡出，进入房屋时始终打开内部视野。

## 移动、交互与物品

- 步行 **6 格/秒（原始基准的 2 倍）**，跑步 **9 格/秒（3 倍）**。Shift 按一下切换，再按一下切回；按住或松开不会重复切换。
- 开局默认跑步、**140%** 视角。左下角显示 WASD / 方向键移动和 Shift 切换步跑的简短提示，触屏显示对应方向按钮提示。
- 跑步有更大的跨步、屈肘摆臂、前倾和腾起动作；驾船使用坐姿及划桨动作。
- 手臂屈肘与挥工具朝向人物正面，跑步躯干向前倾，坐姿双腿向船头伸出；行走时手臂与同侧腿反向摆动。
- 运动以最多 0.14 格的小步进行碰撞检查，防止快速移动穿过薄围栏和河岸。
- 随身物品栏有 **12 格储物格**，最右侧另有 **头、身、背 3 格装备栏**。点击选择；鼠标或触屏拖动可以交换位置或合并同类堆叠；也可以使用“移动”按钮，再点击目标格。装备栏只接受对应类型，草帽、衬衫与背包会同步显示在角色身上。
- 将物品拖到场景，或点击“丢下整组”，会把整组物品留在脚下。靠近按 E 可以拾回，满背包时物品留在地面。
- 木材等地面物品按模型底面贴合实际地板高度，移除悬浮与自转，保留轻微拾取光圈；农舍柴堆与森林落木也调整为贴地摆放。
- 初始 **200 G**、锄头、24 颗种子、浇水壶和镰刀。木材与贝壳可在森林和沙滩拾取。
- 进入小镇绿屋顶的“松果杂货店”，按 E 打开交易。可购买种子和替换农具，也可按件或整组出售物品。
- **120 G** 购买帆布背包后自动放入“背”装备栏，在右下角按钮上方展开 **8 格**，总储物容量为 20 格（另有 3 个装备位）。两块储物空间之间可以直接拖动物品；清空背包后才能卸下、丢弃或出售，防止内容丢失。
- 数字 1–9 跟随物品格的位置选择物品，移动物品后快捷键也随位置变化。空格或非农具物品不会进行耕种操作。
- 购买、拾取和收获使用原子容量检查：空间不足时不扣款、不清除地面物品、不消耗成熟作物。
- 初始还持有一把手枪和一把长剑，默认位于数字 5、6 对应的物品格。左键朝鼠标方向攻击 / F 向面前攻击：手枪射程 11 格、无需补弹，长剑在身前约 2 格范围挥斩；均有冷却，攻击不会穿过树木与建筑。手枪支持边走 / 跑边射击，上半身跟随鼠标瞄准并叠加后坐力，双腿保持前进、横移或后退步态，移速和脚步节奏不受开枪影响。武器可以整理、丢下、拾回和买卖。
- 子弹速度由 18 提升到 **36 格/秒（2 倍）**，从实际枪口发出；增加约 0.1 秒的体素枪口火光与轻微烟雾，子弹使用奶白亮芯、橙色轮廓和最长 1.8 格的渐隐尾迹，关闭柔晕仍可辨认。近距离命中也保留短暂轨迹；每 0.1 格检查碰撞，弹速提高后仍不会穿过薄障碍。
- 森林约有 10 只体素史莱姆，在空地小范围徘徊和弹跳。每只 3 点血，手枪伤害 1、长剑伤害 2；受击短暂变红、轻微震动并向后退开约 0.18–0.25 格，浮出的体素数字显示实际扣血量。击退不会穿过障碍；最后一击仍有变红与淡出反馈。受伤时显示血条，击败后 18–30 秒重新出现。当前史莱姆用于攻击体验，不主动伤害玩家。

## 春日种植与画面

- 在草地或泥土上依次开垦、播种、浇水、用镰刀收获。工具只作用于脚下及周围一格，且不能隔着围栏操作；鼠标点击不会移动角色。鼠标超出范围时，金色高亮吸附到身边最近的可达方格，实际点击操作同一格；可达范围使用更粗的青色边框，无法操作的目标为珊瑚红。
- 镰刀显示朝鼠标方向、沿最近地块轴排列的三格收割预览，挥舞时出现带渐隐尾部的金色弧光。一次同时收割该排内所有成熟作物；未成熟作物与范围外作物不变。空间不足时整次收割不消耗作物。浇水壶、镰刀和锄头使用对应的工具轮廓图标。
- 作物在播种、发芽、幼苗、茂盛、成熟五个状态间切换，每 6 秒进入下一阶段，总计约 24 秒。未浇水时不生长。
- 每次收获获得 1 个白萝卜和 2 颗种子，保留耕地并使土壤变干。菜圃四株示例作物均可实际收获。
- 右上角显示鼠标所指地块的类别、坐标、土壤状态、生长进度和可执行操作，包括新增的沙滩、大海、码头与室内地板。
- 樱花继续覆盖整个可见画面，随镜头移动、缩放和横竖屏变化保持覆盖；河水、草丛、树冠、烟囱保持动态。
- 暖色主光、冷色天空光和柔和补光；最高 **4096 × 4096** 阴影贴图采用固定 5×5 PCF 采样，设备不支持时使用固定泊松采样。根据设备的纹理与渲染目标上限限制尺寸，按实际分辨率对齐阴影像素；固定投影范围，降低阴影偏移并保留柔和接触暗部，细化边缘的同时继续抑制抖动。
- 完整昼夜循环从春日 08:00 开始，默认现实 **10 分钟为游戏一天**，午夜日期加一。太阳从东侧升起、向西侧落下；影子随方向旋转，清晨和傍晚较长、正午较短。
- 夜间采用可辨识地块的蓝色环境光，黄昏有暖色过渡；水面的亮度与阳光反射同步变化，室内灯光增强。
- 共 **14 盏路灯**分布在农场、森林小径、桥边、小镇、沙滩与码头。镂空灯框露出灯罩；17:00–18:15 渐亮，05:30–07:00 渐灭，白天关闭。灯下有暖色渐变光晕，附近人物、工具和环境接受局部照明。
- 路灯光晕避开水域与室内，码头上的光晕跟随地面高度。复用 4 个附近光源，切换位置前先淡出，限制开销与跳变；路灯不额外生成阴影贴图，室内仍由房间灯照明。
- 右上角时钟下方常驻时刻拖动条与暂停 / 继续按钮，可直接预览光影。点击时钟打开详细时间设置，在 **0.25×、0.5×、1×、2×、4×、8×、16×** 之间调整流速，或直达清晨、正午、黄昏、夜晚。流速只影响昼夜。
- ACES、FXAA、高光柔晕与空气透视保留体素面层次；水面与普通材质采用一致颜色处理。柔晕按已经完成色调映射的画面提取亮部，避免阈值过高和曝光重复应用；增强水面反光、浅色花朵与夜间灯光附近的扩散，普通草地保持清晰。可在画面设置切换，兼容回退关闭后期时会显示不可用状态。
- 后期处理固定使用 RGBA8 颜色缓冲；首屏检查材质、相机后期及实际画面采样，连续黑帧时自动绕过后期并恢复材质色彩处理。缩放、画面设置及切回页面时重新检查，正常稳定后停止采样；无法恢复时显示重试提示。
- 支持缩放、全屏、阴影、柔晕、动态、网格和遮挡设置；触屏方向键、步跑切换、互动按钮与物品拖动。
- 鼠标在场景上滚动即可平滑缩放，兼容连续触控板滚动；范围 75%–160%，与缩放按钮和设置滑杆同步。仅改变正交视野大小，45° 朝向及人物跟随保持一致；界面面板滚动与浏览器缩放快捷键互不干扰。

## 操作与导航

新增本地合成音效：草地、泥土、石路、木桥/地板与沙滩的不同脚步声，以及开垦、播种、浇水、收获、拾取、整理、丢下、交易与划船。步声由人物动作的落脚时刻触发，跑步和步行节奏不同，站立、撞墙与驾船不触发步声。首次键盘或鼠标操作后启用声音；设置里可静音、调节音量，失焦/切到后台/打开面板会停止已有声音，商店操作仍可播放交易音效。

音效由 `audio.ts` 中的原创合成器生成。脚步去掉随机脉冲和低频敲击，改为渐起的低通摩擦声；所有音效使用平滑包络与两级低通，整体限制音量与尖峰。跑步声量与落脚节奏独立控制，新增克制的射击、挥剑与史莱姆受击声；有限变体与发声数量限制开销，声音异常不阻断游戏。候选素材站 [Sonniss GDC](https://gdc.sonniss.com/) 的页面可访问，但当前环境不能完成素材下载，本版本未包含第三方录音。

| E / 互动按钮 | 登船、靠岸下船、拾取、与居民交谈、在店内交易 |

小地图与区域大地图均采用与 45° 镜头相同的斜向投影：北方在右上，东方在右下。地形、建筑及玩家位置一起投影，文字保持正向。沿农场中间小径向北到小镇，向东越过木桥到海岸，向西进入森林。

当前进度保留在本次游玩中，**刷新页面会重新开始**。打开地图、帮助、设置或商店会暂停移动、作物生长和昼夜；时间滑杆仍可预览光影。日期会递增，季节目前固定为春季；现已支持实际钓鱼、采矿、Boss 体力与翻滚，尚未加入存档、季节变化和任务系统。

## 开发

```sh
npm install
npm run dev
npm run typecheck
npm run test:world
npm run build
```

- `geography.ts`、`world.ts`、`worldDistricts.ts`：共同地图数据、四区场景布置、通行与遮挡；`WorldMap.tsx` 使用同一套道路、建筑、菜圃、木桥和码头位置。
- `buildings.ts`：开放门口、室内细节、墙壁和家具碰撞。
- `ocean.ts`、`boat.ts`：波浪着色器、海上生态、小船规则与动画；`riverFish.ts`：河流鱼影的随机生命周期、河道轨迹和动画复用。
- `npcs.ts`、`character.ts`、`movement.ts`：居民路线、人物姿态、步跑切换及分步碰撞。
- `inventory.ts`、`droppedItems.ts`：物品规则、堆叠、金币、商店、背包和地面拾取。
- `farming.ts`、`farmView.ts`：种植状态、选格吸附、方向范围收割、作物与工具效果；`actionEffects.ts`：镰刀与长剑弧光；`combat.ts`：森林史莱姆、武器冷却、子弹碰撞、受击与重生；`damageNumbers.ts`：复用的体素伤害数字。
- `lighting.ts`、`stableShadows.ts`、`contactShadows.ts`、`streetLights.ts`：昼夜光影、阴影稳定化、接触暗部及自动路灯；`ambience.ts`、`cherryBlossoms.ts`：水流和全屏樱花。
- `dayNight.ts`、`TimeControls.tsx`：昼夜时钟、太阳轨迹、流速与时间控制；`mapProjection.ts`：与镜头一致的地图投影。
- `audio.ts`：原声音效合成、地面材质对应的脚步、音量/静音、首次交互解锁、声音复用与清理。
- `engine.ts`、`renderGuard.ts`：输入、固定镜头、游戏帧、画面输出检查和兼容回退、交互和商店位置校验。
- `FarmGame.tsx`、`InventoryUI.tsx`、`ShopPanel.tsx`、`WorldMap.tsx`、`TileInspector.tsx`：游戏界面。

以上游戏文件位于 `components/game/`。

## 验证范围

TypeScript 类型检查和 Babylon NullEngine 规则检查涵盖：7680 格、半格精度的全区域及房屋入口连通性、墙壁与家具碰撞、桥梁、步跑切换与姿态、船只边界与靠岸、交易和堆叠守恒、背包容量、丢下与拾回、背包满时的原子收获、原有种植循环、海面相关场景和鱼鸟及居民运动、材质就绪、场景帧、阴影跟随与开关、全屏樱花覆盖及缩放回归。

昼夜与方向回归涵盖：地图轴线与 Babylon 相机矩阵一致、手与工具握点在身前、前倾与坐姿朝向、时间倍率/暂停/跨日、太阳轨迹、阴影转向与长短、夜色不会被误认为黑帧，以及水面和灯笼随时间更新。

阴影与路灯回归使用 Babylon 实际阴影矩阵检查镜头微移与整像素对齐；另覆盖太阳持续转向、14 个灯位不与树木/墙壁重叠、道路与房屋连通性、清晨/傍晚开关、灯下光晕避水、附近光源复用及室内隔离。

海洋生灵回归比较 Babylon 世界矩阵变换后的头部方向与实际位移方向，覆盖所有海鸥与鱼影的多段轨迹、所有跃鱼的起跳/最高点/落水姿态，以及波面落点、涟漪和动态关闭。

河流鱼影回归连续模拟两分钟，检查多轮随机出没、渐入渐出、双向游动、模型顶点不越河岸/桥梁、头部朝向、暂停恢复及网格/材质数量保持不变。

音效检查包含两种采样率下的有限、非静音、无削波音频信号，地面声映射、首次交互初始化、静音/零音量/后台屏蔽、声音复用和资源释放；另检查步跑动作的落脚节奏、木材底面在不同地板高度下贴地，以及高分辨率和低设备上限的阴影路径。

交互回归检查装备类型约束、满背包卸下保护、地块吸附与实际目标一致、四方向三格收割、整次收割容量守恒、武器冷却和障碍阻挡、史莱姆血量与重生，以及特效和子弹资源复用。音效另检查三种变体的峰值、均方根电平和脚步高频变化，防止刺耳的脉冲回归。

战斗反馈回归检查变红恢复、震动与碰撞分离、实际伤害数字、致命一击淡出、资源池复用、暂停与减少动态、不同帧率的击退距离及障碍阻挡。移动射击检查步行 / 跑步速度、四方向步态、后坐力独立叠加、脚步节奏连续，以及冷却和碰撞约束。

渲染回归另涵盖：柔晕在实际相机后期链中的接入/移除/恢复、显示空间亮部提取与曝光、驱动报告支持浮点缓冲时仍选择 RGBA8、黑帧与有效画面区分、瞬时黑帧容忍、失败后的直接渲染、后期解绑与色彩恢复、异步读取取消、超时及异常提示。亮度与像素样本为测试输入。

NullEngine 没有 GPU。检查仅模拟其原始纹理上传完成信号，不等同于真实 WebGL 的 GLSL、阴影过滤、鼠标拖拽、射线拾取、画面或帧率验收。内部浏览器预览服务不可用，真实设备视觉和操作效果仍需通过试玩验收。
