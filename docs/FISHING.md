# 松溪钓鱼

## 操作

- 初始随身物品栏第 **7 格**是竹钓竿，不移动原先 1–6 格的农具和武器。
- 站在河岸、木桥边、海岸或码头，朝水面 **按住空格蓄力、松开甩竿**。也可按住鼠标/触屏水面蓄力，方向在开始蓄力时锁定。
- 玩家头顶只有一条 **132px 小力度条**：1.1 秒从最小升到最大，再用 1.1 秒回落，持续往返。松开时力度越大落点越远；水面圆圈实时预示落点。力度映射到前方 6 格内的首段可钓水域，不会甩到对岸陆地。
- **未提竿前没有钓鱼提示板**：蓄力、甩出、等待和咬钩阶段都保留水面视野。等待约 2–4 秒，浮漂周围持续出现激烈水花，水面上方亮出像素叹号后，在 1.65 秒内按空格或点击水面提竿；成功提竿才显示搏斗面板。
- 控鱼时 **按住左键 / 空格 / 面板按钮上浮，松开下沉**；让绿色条包住鱼，钓获进度满格即可成功。开头有 1 秒宽容，进度归零或超时会逃鱼。
- **Esc 收竿**，搏斗时也可点 ×。打开帮助、地图、设置或商店时，尚未甩出的蓄力安全取消，落水后的钓线/搏斗暂停；失焦、触屏取消都不会误触甩竿。鼠标松开不会释放另一套正在按住的空格输入，后台不推进游戏。
- 河流：鲤鱼、河鲈；海域：沙丁鱼、红鲷。鱼每格可堆叠 20 条，可在杂货店出售；钓竿丢失后也能重新购买。

## 状态与动画

`idle → charging（按住往返蓄力）→ casting（松开甩出）→ waiting → bite（水花 + !）→ reeling（空格提竿后开面板）→ catching → idle`

未及时提竿或控鱼失败：`bite / reeling → escaped → idle`。

- 蓄力时角色把竹竿举到头后，固定位置和朝向；松开后向前挥出，显示连接竿尖的鱼线、弧线浮漂与水花。
- 咬钩窗口中 24 个复用水滴持续错峰飞溅，涟漪加速扩散、浮漂猛烈下沉，叹号跟随实际落钩水面投影；不会在远离水面的面板内发出提示。减少动态时保持静态叹号和飞溅形状，信号不会消失。
- 成功后使用原创透明 RGBA 像素鱼贴图，先从落钩水面下方升起（0.8 秒），再投影到屏幕，接续同一 SVG 贴图的缩小吸入动画（0.75 秒）。
- 飞行终点由实际可堆叠或空物品格的 DOM 边界实时计算，支持背包格、缩放、窗口尺寸变化。
- 动画结束才一次性加入库存、播放拾取音效并点亮目标格。钓鱼期间禁止物品交换、丢弃、拾取和其他互动，避免目的格发生变化。
- 抛竿前检查鱼种池所需的储物空间；兜底失败也不会吞鱼，会放在脚边。成功动画不能取消；“回到菜圃旁”会先结算已钓获的鱼。
- 减少动态时降低出水高度并取消额外弧线、旋转和水滴，不改变玩法时序。

## 文件

- `components/game/fishing.ts`：与渲染无关的状态机、鱼种池、水域/射程/障碍校验、目标物品格选择。
- `components/game/fishingView.ts`：复用网格的浮漂、鱼线、水花、真实水域出鱼贴图与投影飞入动画。
- `components/game/FishingOverlay.tsx`、`components/game/fishing.css`：中文钓鱼面板、触屏控制和响应式控鱼条。面板独立采样状态，不让整个 HUD 每帧重渲染。
- `components/game/fishSprites.ts`、`public/items/fish-*.svg`：同源像素网格与四组配色；`fishSpriteSVG(id)` 可重新生成静态 SVG，`createFishPixels(id)` 生成 Babylon 贴图数据。无第三方素材。
- `components/game/engine.ts`：输入、暂停、移动互斥、音效、背包结算与资源销毁。

## 验证

```sh
npm run typecheck
npm run test:fishing
npm run test:world
npm run test:fishing:browser
```

浏览器脚本默认使用已经运行的 `http://127.0.0.1:5177`，不会另开游戏服务；可传入其他现有预览 URL。默认 Chrome 路径为 Windows 安装位置，也可设置 `CHROME_PATH`。脚本以独立临时配置启动无头 Chromium，经实际输入完成钓获，验证暂停、触屏按住/释放、取消和小屏布局，截图保存在 `.cache/fishing-*.png`，随后清理浏览器进程及临时配置。

世界回归还覆盖：真实地形的亚格岸边落钩、竿尖姿势、SVG/RGBA 同源、出水高度、飞行终点、暂停/减少动态、一次性入包与效果网格复用。
