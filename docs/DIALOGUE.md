# 交互式 NPC 对话

## 操作

- 走近可接触的镇民，点击「和某某交谈」；原有 E 互动也可开启对话。
- 气泡按字逐个显示，伴随轻柔的「哒哒」声。中文、组合字符和表情不会拆碎；标点会稍作停顿。
- 文字还没打完：点击气泡或背景，只补全当前段，不进入下一段，也不会补播一串声音。
- 当前段显示完：再点击才进入下一段。每段清空旧文字，从空气泡重新打字，不会自动连播。
- NPC 一轮多段话全部结束后才出现玩家选项；选择后可以继续多段回答、追问、返回话题或告别。
- Enter / 空格 / E 可补全或继续，Tab 可选择按钮，Esc / 右上角关闭按钮结束。选项不受背景点击替代，也不会点击穿透攻击NPC。
- 对话期间世界模拟与玩家操作暂停，NPC与玩家面对面；结束后恢复。切到后台或打开其它面板时暂停打字与音效，恢复时不补播。
- 音效遵守「游戏音效」和音量设置；无需下载录音。文字仍正常显示，即使音频设备不可用。

## 内容与实现

- 五位镇民（莉芙、阿松、米娅、奥利、艾达）各有两段开场、不同话题、追问和告别。受伤/惊慌有专用短回应。
- `dialogue.ts`：纯状态机，校验节点与选项引用，逐grapheme揭示、标点停顿、点击跳过/继续、分支、关闭重开。
- `dialogueContent.ts`：独立内容图，不修改背包或金币。
- `DialogueOverlay.tsx` / `dialogue.css`：气泡、选项、键盘焦点和手机布局；每段用serial重置文字与滚动。
- `engine.ts`：可达NPC查询、面对面与世界冻结、输入隔离、独立对话更新事件。
- `audio.ts`：40ms程序化短敲击声，三种变化；缓存音频、限制播放频率、静音/音量/关闭处理。
